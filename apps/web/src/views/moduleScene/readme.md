
在`./showme` 中是更基础的教学练习

跟随B站上的教学视频，学习three.js
主要的内容：
- 通过模块化的方式来创建项目中的各个内容，目前模块组织方式还不是很好
- 贴图的内容存放在 pinia store 中，进行集中管理。在 utils/AssetLoader 中加载资源
- 大部分内容都在 Environment 中，组件场景中的各类东西
- 在 Physics 中添加物理效果，使用 RAPIER 库，创建
刚体（Rigidbody）：是物理世界的“身份ID”和“计算器”。它告诉物理引擎：“这个物体受重力影响，可以被推动，也能推动别人”。它负责计算速度、质量、摩擦力和受力情况。

碰撞体（Collider）：是物理世界的“皮肤”和“边界”。它告诉物理引擎：“这个物体占多大地方，哪块区域不能被其他东西穿过”。它负责检测两个物体是否挨着了（触发）或是否撞上了（碰撞）。
- 在 utils/Loop 中管理循环，utils/Resizer 中适配界面缩放
- UI/Preloader 中进行了场景初始化时的加载等待效果

主要的难点在于
1. 如何组织模块
2. 加入物理引擎之后，物体的计算，`worlToLocal` `matrixWorld` `invert`。当网格放在group中，祖先节点的旋转平移缩放会对当前网络有影响，但是对网格的碰撞体不会有影响，要使物理引擎中的碰撞体对网格的更新不被影响，需要对祖先节点的世界矩阵求逆，计算出网格原始的位置旋转缩放
